# Internationalization

## Rules

- Messages live in `src/messages/<locale>.json`. Add each key to every locale in the same change: the types do not prove this, a key missing from another locale still compiles.
- Follow the key style already in `src/messages/en.json`. Group keys per feature.
- Localize, do not translate word for word: write each message the way a native speaker would say it, and adapt examples and emphasis to that locale's readers. Keep the meaning and facts the same.
- No hardcoded user-facing strings, including `alt`, `aria-label` and metadata.
- Never build keys from variables. A complete key from a typed `as const` list is fine.
- Read messages inside functions. A call at module level freezes one locale, also across server requests: constants hold keys or become functions, and Zod schemas take a factory or a lazy message.
- Add a test that fails when locale files have different keys.
- URLs: the default locale at `/`, others under a prefix (`/tr`). Never redirect by cookie or browser language. Pages declare `hreflang` with `x-default`, and the sitemap lists every locale.
- Read the locale from the library, never from `window.location` or by parsing the URL.
- Plurals belong in the message, not in code. For case and sorting use `toLocaleUpperCase(locale)`, `toLocaleLowerCase(locale)` and `Intl.Collator(locale)`; plain `toUpperCase()` and `sort()` give wrong results in some languages.

## next-intl

- `useTranslations` in Client Components and sync Server Components; `getTranslations` in async server code and `generateMetadata`.
- Routing config, `Link`, `redirect` and `useRouter` come from `@/i18n/routing`, not from `next/navigation`.
- `localePrefix: "as-needed"`, `localeDetection: false`, `localeCookie: false`.
- Register `Messages` in next-intl's `AppConfig` so a missing key is a type error. Nesting is optional; no `.` in key names.

## Paraglide JS

- Each key is a function: `import * as m from "@/paraglide/messages.js"`, then `m.cart_title()`. Keys are flat.
- The locale comes from `@/paraglide/runtime.js` (`getLocale`, `setLocale`). `setLocale` reloads the page by default; keep it so the URL and server HTML agree.
- Strategy `["url", "baseLocale"]`, with one `urlPatterns` entry for `/` and one catch-all, otherwise `localizeHref` returns `/tr/`.
- `src/paraglide/` is generated on install and build. Never edit it; change `src/messages/` or `project.inlang/settings.json`.
